# CX 快速解码

把 **cx-E2EE 网页端「图片区域打码」的还原**做成一个桌面小工具：先把密码填好，然后复制图片 / 框选截图 / 拖入文件，就能拿回原图。

> **算法不是本项目写的。**
> 混淆与解混淆都来自他人仓库 **[cxxy161/cx-E2EE](https://github.com/cxxy161/cx-E2EE)**（`src/image-crypto.js` 里的 V3 区域打码）。
> 本项目只做了三件事：把算法移植成 C#（与网页端逐字节对齐）、套一层 Windows 桌面交互、加了些顺手的小功能。
> 算法部分的使用与再分发请遵循上游仓库的许可，详见 [`NOTICE.md`](NOTICE.md)。

## 功能

- **剪贴板解码**：复制打码图后 `Ctrl+Alt+Q`（或点按钮 / 密码框回车）
- **截图解码**：`Ctrl+Alt+S` 后在屏幕上框选
- **拖入解码**：把图片直接拖进窗口，或「打开图片」
- 密码预输入并记住；解出的图自动进剪贴板
- 结果以**浮层**贴在窗口上/下方，几秒后自动消失，窗口尺寸不变
- **悬浮球模式**：左键剪贴板、右键托盘菜单、`Ctrl+右键` 截图（所有组合都能在设置里改）
- **图库**：本次运行解出的图片，可预览、另存、批量导出
- 空闲自动降耗：降低进程优先级并收缩内存

## 要知道的限制

- 只支持 **PNG** 打码图（网页端 8px 边框 + 像素最低位存区域表）。网页端导出的 **JPEG**（64px 边框鲁棒码）暂不支持。
- 元数据在像素最低位：图片不能缩放、重压 JPEG。截图要求屏幕上那张图是 **1:1** 显示，否则最低位已经被抹掉——程序会检测到并改用原文件或直接说明。
- 配置在 `文档\CxQuickDecode\cxq.config.json`（想便携就在 exe 旁边放个空文件 `cxq.portable`）。

## 构建

需要 .NET 8 SDK（WinForms）：

```bash
bash build.sh            # 只编译
bash build.sh publish    # 编译并产出单文件 exe 到 dist/
```

首次 `dotnet restore` 需要访问 NuGet（依赖 `Svg` 包，用于把 SVG 图标按目标尺寸栅格化）。
