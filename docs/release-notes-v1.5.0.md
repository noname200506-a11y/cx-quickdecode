# CX 快速解码 v1.5.0

把 **cx-E2EE 网页端「图片区域打码」的还原**做成一个 Windows 桌面小工具：先把密码填好，然后复制图片 / 框选截图 / 拖入文件，就能拿回原图。

> **算法不是本项目写的。** 混淆与解混淆来自他人仓库 **[cxxy161/cx-E2EE](https://github.com/cxxy161/cx-E2EE)**（`src/image-crypto.js` 的 V3 区域打码）。
> 本项目只做了 C# 移植（与网页端逐字节对齐）+ Windows 交互层 + 一些顺手功能。算法部分的使用与再分发请遵循上游许可。

## 功能

- **剪贴板解码**：复制打码图后 `Ctrl+Alt+Q`（或点按钮 / 密码框回车）
- **截图解码**：`Ctrl+Alt+S` 后在屏幕上框选
- **拖入解码**：图片直接拖进窗口，或「打开图片」
- 密码预输入并记住；解出的图自动进剪贴板
- 结果以**浮层**贴在窗口上/下方，几秒后自动消失（鼠标停在上面不消失），点浮层看大图；窗口尺寸固定不变
- **悬浮球模式**：左键剪贴板、右键托盘菜单、`Ctrl+右键` 截图；所有组合可在设置里改
- **图库**：本次运行解出的图片，可预览、另存、批量导出
- 空闲自动降耗：降低进程优先级并收缩内存

## 快速上手

1. 双击 `CX快速解码.exe`，在密码框里填网页端的打码密码（会自动记住）
2. 复制一张打码图 → 按 `Ctrl+Alt+Q`；或者直接把它拖进窗口
3. 绿色提示 + 缩略浮层 = 成功，结果已在剪贴板；点浮层可另存为 PNG

## 已知限制

- 只支持 **PNG** 打码图（网页端 8px 边框 + 像素最低位存区域表）。网页端导出的 **JPEG**（64px 边框鲁棒码）暂不支持。
- 元数据在像素最低位：图片不能缩放、不能重压 JPEG；**截图要求屏幕上那张图 1:1 显示**，否则最低位已被抹掉（程序会检测到并改用原文件或直接提示）。
- 配置在 `文档\CxQuickDecode\cxq.config.json`；想便携就在 exe 旁放个空文件 `cxq.portable`。
